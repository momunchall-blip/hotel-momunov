# 🏨 Hotel Analytics · Кыргызстан

Сквозной проект по дисциплине «Big Data и анализ данных», вариант № 8 — мониторинг и оценка эффективности работы отелей.
Автор: Момунов Акыл, ПИ-2-23.

Интерактивный дашборд на Streamlit: KPI и карта отелей, сезонность, сегментация (K-means), прогноз загрузки до конца 2026 г.,
калькулятор среднего чека (МНК и Random Forest), Probit-модель вероятности высокой загрузки.

## Запуск локально
```
pip install -r requirements.txt
streamlit run app.py
```

## Файлы
- `app.py` — приложение
- `hotel_clean.csv` — очищенный датасет (результат лабораторной работы 1.1)
- `.streamlit/config.toml` — тёмная тема
- `requirements.txt` — зависимости
